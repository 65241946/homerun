## Decisions Made

| Decision | Rationale |
|---|---|
| 新闻作为单一业务模块，不再内部细分 | 用户明确要求 |
| 公共原始数据获取、标准化、汇总和消息分发可修改基座 | 用户明确授权的数据层边界 |
| 钱包业务规则、信号、过滤和下单决策位于独立策略层 | 避免策略侵入基座并支持后续插拔 |
| 新闻、天气、加密、体育原策略保持不变 | 本次迭代业务边界 |
| 当前只做研究和设计，不改交易代码 | brainstorming 设计批准门禁 |
| 不再新增平行的 OrderIntent/模块接口体系 | HOMERUN 已有 Opportunity、TradeSignal、TraderDecision、TraderOrder、TraderPosition 完整链路 |
| 外部框架只证明架构/运行模式，不视为盈利证据 | 实盘可运行能力与策略收益是两类证据 |
| “没有实盘订单”不得直接归因于策略 | 实盘账户、凭证、Trader mode 或 live permission 未配置时，零实盘单是预期状态；必须逐层检查 |

## Errors Encountered

| Error | Attempt | Resolution |
|---|---:|---|
| 工作区根目录已有其他项目的 planning 文件 | 1 | 在 `docs/research/wallet-consensus-alpha-v1/` 建立独立研究记录，不覆盖旧文件 |
| PowerShell 将双引号正则中的 `|` 解析为管道 | 1 | 改用单引号执行只读 `rg`；未产生文件改动 |
| PowerShell 在聚合 Git 仓库信息时出现空管道解析错误 | 1 | 改为先累积对象数组再统一输出 JSON；未运行仓库代码 |
| GitHub 未认证 REST 批量查询受到限流 | 1 | 改用固定本地 clone、`git ls-remote`、官方网页与单项目源码核验；未根据缺失响应作推断 |
| 一次宽范围 `rg` 输出过大并被截断 | 1 | 改为按模型、策略、worker 和执行链的具体文件/符号做定向只读核验 |
| PowerShell 在 `foreach` 后直接接格式化管道时报空管道 | 1 | 先写入 `$rows` 数组再统一输出；文档检查随后通过 |
